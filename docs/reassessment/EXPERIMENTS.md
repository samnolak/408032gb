# Реестр экспериментов (предрегистрация) — переоценка 2026-10-09, редакция 2 после ревью

Правило: эксперимент регистрируется **до** запуска: гипотеза, бейзлайн, одинаковые модель/квант/промпт/контекст, состояние
(cold/warm), команды, метрики, число повторов, порог остановки. Результат без литерального лога (`raw.jsonl`, `meta.json`,
вывод команд) — недействителен. Не запущено — `NOT RUN`, не `PASS`.

Общие условия для всех GPU-экспериментов:
- SHA этого репозитория и движка, версия драйвера/CUDA, `nvidia-smi -q` до/после, температура и частоты в ходе прогона;
- ≥ 3 повтора, p50/p95/min/max; первый прогон после загрузки — отдельно как «холодный»;
- single-stream числа и агрегатная пропускная способность — в разных колонках;
- декод меряется **при уже заполненном контексте** (вход L, затем ≥ 512 токенов вывода); TTFT отдельно;
- инструменты: `tools/bench/run_matrix.py`, `tools/bench/probes.py` (OpenAI API), `scripts/diag/*`, `tools/roofline.py` для
  предсказания до замера (предсказание записывается заранее — так видно, где модель ошибается).

Статусы: `NOT RUN` | `RUNNING` | `DONE (evidence: …)` | `STOPPED (почему)`.

**Критерий заказчика (сквозной, D1 ADR-012):** PASS только если на одной и той же конфигурации (модель + квант ≥ 4 бит по
`tools/gguf_quant_audit.py` + движок) одновременно: декод single-stream p50 **≥ 50 tok/s при заполненном контексте** (промпт
≥ 262 144 − N токенов, затем вывод N ≥ 512 токенов; 80–100+ — желательная цель), пробы K1 на этой длине пройдены, кэш префиксов
работает (B3). Любой эксперимент ниже, который меряет только короткий контекст, — характеризация, а не PASS по требованию.
Предсказание границы (`tools/roofline.py`, с теми же `--spec-k`/`--overlap`, что у движка) записывается до замера; сравнение —
`tools/bench/vs_roofline.py`.
