# BIOS — совместный пошаговый план с владельцем (2026-10-09)

Полная таблица настроек с эффектами, рисками и источниками — `research/R4-hardware.md`, разд. 9. Здесь — **порядок работы** и
**журнал**. Пути меню для HUANANZHI H12D-8D — **UNKNOWN**: известны только для другой AMI-платформы Milan (ROCm docs, VERIFIED в R4);
названия сверяются по фотографиям владельца.

## Правила
0. **Драйвер NVIDIA не патчится** (ADR-012.2, подтверждено владельцем 2026-10-12, ADR-012.3): никаких P2P-патчей
   (tinygrad/aikitoria) без нового явного разрешения. P2P проверяется только штатными средствами после появления сервера
   (`R0-HARDWARE-CHECKS.md` (b)). Шаги 2 и 6 ниже больше не служат предпосылкой патча.
1. **Никогда:** прошивка BIOS/VBIOS, изменение напряжений, разгон памяти выше паспорта DIMM, `RMForceStaticBar1=1`,
   «Load Optimized Defaults» без необходимости (сбрасывает IOMMU и порядок загрузки).
2. **Одна настройка — одна перезагрузка.** После каждой: проверка из таблицы, при аномалии — откат только этой настройки.
3. Если машина — хост Proxmox: окно простоя согласует владелец (перезагрузка останавливает все VM). IOMMU на таком хосте не выключать.
4. Перед ReBAR (шаг 2) убедиться, что ОС загружена в UEFI: `ls /sys/firmware/efi` — иначе отключение CSM сломает загрузку.
5. cTDP/лимиты мощности — только после того, как CPU точно опознан по CPUID (F1), и с контролем VRM/температур в BMC.

## Шаг 0 — «до» (ничего не меняем)
- [ ] Владелец фотографирует все страницы BIOS: Main (версия, дата), Advanced → PCI Subsystem, все подменю AMD CBS
  (CPU / DF / UMC / NBIO / SMU / Security), Boot, Server Mgmt. Фото кладутся в `docs/evidence/bios/2026-10-XX-before/`.
- [ ] Есть удалённая консоль BMC (KVM) или монитор на время POST; известно, где перемычка сброса CMOS.
- [ ] Снят полный комплект `scripts/diag/collect.sh --sudo` + `bench_all.sh` (эталон «до»).

## Очередь шагов (каждый — только после разбора результатов предыдущего)
| порядок | настройка (R4 §9, №) | зачем нам | условие начала |
|---|---|---|---|
| 1 | Above 4G Decoding = Enabled (№1) | адреса для больших BAR 4 карт | обычно уже включено — только сверить по фото |
| 2 | Re-Size BAR = Enabled (№2) | **не как предпосылка P2P-патча** — патч драйвера не делается (ADR-012.2, ADR-012.3); только если замеры R0 (F9 BAR1, F14) покажут пользу для штатного пути, по отдельному согласию владельца | UEFI-загрузка подтверждена; согласие владельца на этот шаг |
| 3 | Частота памяти = 3200, если ниже (№14) | полоса CPU-яруса экспертов | F5 < 3200 и DIMM рассчитаны на 3200 |
| 4 | NPS1 (база) → NPS4 (опыт) (№7) | максимум полосы одного CPU-пула vs локальность | после F6 в текущем режиме |
| 5 | Determinism = Power (№8), APBDIS=1 + Fixed SOC P-state P0 (№10) | частоты, задержки Infinity Fabric | после шагов 1–4 |
| 6 | IOMMU: на голом железе — Enabled + `iommu=pt` в ядре (№5) | **снято**: было требованием P2P-патча, а патч не делается (ADR-012.2, ADR-012.3); на хосте Proxmox IOMMU не трогать (правило 3) | не выполняется без нового явного решения владельца |
| 7 | прочее (№11–17) | точная настройка | по замерам |
