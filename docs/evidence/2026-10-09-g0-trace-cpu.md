## Checks
- The prompt part of a trace with 40 generated tokens equals the prompt-only trace (`G0_GEN_TOKENS=0`) for p0: True.
- Batch shape changes routing slightly: `-b 300 -ub 300` vs `-b 64 -ub 32`, same token ids, prompt only. Per layer, tokens whose
  expert SET differs: layers 1-4 none; p0 layer 6: 2 of 300, layer 10: 7, layer 11: 17; p3 layer 11: 2 of 300. Sparse and growing
  with depth = floating-point differences between batch shapes propagated through layers (near-tied router scores of random
  weights), not a row-ordering bug (that would misalign almost every token). Consequence for M1: record `-b/-ub` with every
  trace; on the real model measure how often routing changes with batch shape (CPU vs GPU, prefill vs decode) before trusting
  a static placement chosen from prefill traces.

Status: tool CONFIRMED working on CPU with the real glm5-next graph; routing statistics of any real model NOT RUN.
