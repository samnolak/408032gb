## Findings (CONFIRMED)

1. **SwiGLU clamp for GLM is pre-activation**: `silu(min(gate, L)) * clamp(up, -L, L)` via ggml_swiglu_clamp
   (src/llama-graph.cpp 2246-2250 for routed experts, 1856 for shared/dense). Other architectures in
   llama.cpp use `min(silu(gate), L)`. Applies to routed and shared experts.
2. **Router**: selection by sigmoid + e_score_correction_bias, weights from the unbiased sigmoid,
   normalised with the sum clamped at 6.1035e-5, times 2.5 (build_moe_ffn, src/llama-graph.cpp 2015+).
3. **Indexer cache is f16 by default**: pooled keys match the oracle to 3e-4 with the default cache and to
   8e-8 once key and gate are rounded to f16 as stored.
4. **Attention with the default f16 cache** rounds q, the cached latent and the probabilities to f16
   (reproduced to 6.4e-8 with flash attention off); CPU flash attention adds more (4.2e-4 total).
   The parity reference therefore runs with -ctk f32 -ctv f32 -fa off.
5. **Index selection ties**: ReLU makes many pool scores exactly 0. ggml_top_k on CPU uses
   std::partial_sort (ggml-cpu/ops.cpp), whose order among equal scores is unspecified; the CUDA
   implementation differs again. Token-level parity across backends can diverge on such ties; the
   test accepts any valid top-k and checks exact equality when there is no tie at the boundary.
6. **Pool visibility**: token t sees pool b only when complete, 4(b+1) <= t+1, plus the incomplete tail.
7. **Sinkhorn** after 20 iterations is exactly normalised over src and only approximately over dst
   (up to 1.8% on skewed inputs); kernels must reproduce the 20-iteration result.
8. **MLA latent cache is one MQA head**: head_count_kv = 1 on DSA layers, 0 on KDA layers (recurrent).
