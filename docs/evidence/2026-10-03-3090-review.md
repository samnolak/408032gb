## Caveats found in review
1. **Synthetic pack.** Only MoE layers 0 and 11 hold random blobs, the other 40 read as zeros; dense weights are small random
   values. Byte-identity tests therefore exercise the code paths, not the arithmetic on realistic values in 40 of 42 MoE layers.
2. **Decode 19.7 tok/s is a ceiling of the dense path, not a forecast.** The same log reports 99.2% of experts served from
   VRAM on a 24 GiB card with a synthetic routing profile. With real routing the share of experts outside VRAM is the main
   cost (upstream reports 13% of experts in VRAM on a 32 GiB card). PROBLEMS.md says "оценка скорости переносима" - that holds
   for the dense part only (36.1 ms per token there), not for decode as a whole.
3. **Prefill figures need the whole pack in RAM** (251 GiB on that host; the tier pinned 141.91 GiB). The 4x4080 server has
   128 GB of RAM, so those figures do not transfer either.
4. **"Canonical weights" section in AGENTS.md** was written as a global rule ("no other real weights, none are to be
   downloaded"). On main it is now scoped to the 3090 host; the weights for the 4x4080 server remain an open question.
5. **Neither base reads the UD-Q4_K_XL GGUF today.** Base A needs its own pack; a GGUF->pack converter re-quantises already
   quantised weights. Base B (ADR-009) reads GGUF with architecture `glm5next` (the same string as this GGUF) but lists expert
   kernels for Q2_K, Q3_K, IQ2_S, IQ3_S, IQ4_XS only (its docs/GLM53_FLASH.md:126-127) - PROVISIONAL, by reading.
6. PROBLEMS.md of the fork still calls `tools/glm_pack.py` Windows-only although commit 13bbdc1 (patch 0006) ports it to Linux;
   the list of questions has two items numbered 6. Patch 0006 still reads a safetensors checkpoint, which that host does not have.
7. Patch 0004, read here: the posix path retries short reads and EINTR, tolerates a window running past the end of the file,
   falls back to a buffered descriptor when `O_DIRECT` is refused at open. The per-thread descriptor in `read_blob` is never
   closed (same as the Windows original). No defect found by reading; built for sm_89 and sm_86 in CI from this commit on.
